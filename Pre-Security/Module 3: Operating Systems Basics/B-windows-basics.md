# Section B: Windows Basics

Before Windows had its current polished look, Microsoft operating systems were much simpler.

Early computers ran MS-DOS, which provided a text-based environment where users had to type commands instead of clicking icons.

In 1985, Microsoft released Windows 1.0, which introduced a graphical user interface (GUI) built on top of DOS. Over time, Windows added more features, memory controls, and user-oriented capabilities, eventually becoming a complete operating system.

---

## Logging In & Authentication

Before gaining access to the Windows desktop, a user must authenticate to the system.

The authentication process:

- Verifies the user's identity.
- Determines the actions the user is allowed to perform.
- Allows access through methods such as passwords, PINs, or other verification methods.

When a Windows system starts, it displays a login screen where a user account must be selected and authenticated.

Each user is assigned a set of permission levels that determine their access to files, settings, and system functionality.

### Common Windows Account Types

#### Guest

A restricted account intended for temporary access, with minimal permissions and no ability to change system settings.

#### Standard

A user account intended for everyday tasks, such as running applications and changing personal settings, without access to system-wide changes.

#### Administrator

A privileged account with extensive control over the system, including software installation, configuration changes, and user management.

## The Windows Desktop

The Windows desktop is the main graphical workspace where users interact with the operating system.

### 1. Desktop

The main workspace where files, folders, and shortcuts are placed.

### 2. Taskbar

A control strip that provides access to applications, system tools, settings, and notifications.

### 3. Desktop Icons

Shortcuts to items such as the Recycle Bin, folders, and frequently used applications.

Desktop icons can be customized according to the user's needs.

### 4. Start Menu

The primary way to access applications, files, folders, settings, and power options.

From the Start Menu, users can also:

- Log out
- Restart the computer
- Shut down the computer

### 5. Search

Allows users to quickly find applications, files, folders, and system settings by using keywords.

### 6. Task View

Allows users to view currently open windows and quickly switch between them.

### 7. Pinned Apps & Folders

Frequently used applications and folders can be pinned for quick access.

### 8. Network & Audio Settings

The Windows desktop provides quick access to network and audio settings.

These settings allow users to manage:

- Network connections
- Wi-Fi and other network options
- Audio and volume settings

### 9. Date & Time

Windows provides access to date and time settings from the desktop.

This allows users to:

- View the current date and time.
- Open the calendar.
- Modify date and time settings.

### 10. Notifications

The notification area displays notifications from the computer and installed applications.

Network and other system settings can also be accessed from this area.

## Built-in Tools & Apps

Windows comes with many useful built-in tools and applications that can be used for everyday tasks.

Beyond the wide range of settings available for managing the system, Windows includes simple but useful tools such as:

- **Notepad** — used for editing text files.
- **File Explorer** — used for navigating and managing files.

These tools are available immediately and form part of everyday Windows usage.

They can be accessed through the **Start Menu** and **Search**.

## Getting System Information

Windows includes a built-in **Settings** app that allows users to configure and view information about their system.

Within the Settings app, there is a useful section called **About**, which provides key details about the system.

The **About** page provides an overview of:

- System information
- Device information
- Windows information
- Security-related information

This information can be useful when identifying the hardware, operating system, and configuration of a Windows computer.

## File Exploration & Management

Windows uses a hierarchical folder structure, meaning folders can contain other folders and files inside them.

This structure helps keep data organized and makes it easier to locate information as the system grows larger.

Common locations include:

- **Desktop**
- **Documents**
- **Downloads**

These serve as primary directories for storing files. Within these locations, subfolders can be used to group related files together.

## Application Management

Applications are the programs and tools you use to perform tasks on your computer, from browsing the web and editing photos to managing settings on your PC.

We already discussed a few of the built-in applications Windows provides, but knowing how to **install, update, and remove applications** is a core skill for everyday Windows use.

Updating your OS or apps is like changing flights or reserving a seat.

- **Updating an OS or app** → Changing flights or reserving a seat
- **Installing a new app** → Scheduling a new flight
- **Removing an app** → Cancelling a booking you no longer need

These three processes enable you to make the necessary changes to your system, ensuring you have exactly what you need and that your system remains secure.

### Updating Your Applications

Keeping the operating system and applications up to date is an important part of maintaining a secure and stable system.

Updates may include:

- Security patches
- Performance improvements
- Bug fixes

#### Windows Updates

Windows includes a built-in update tool called **Windows Update**, which keeps the operating system, some native applications, and security features up to date.

Windows Update can be accessed through the **Settings** app and may install updates automatically, depending on the system configuration.

#### Updating Apps

Apps update in different ways depending on how the software is installed.

- Built-in apps may update automatically in the background.
- Third-party apps often include their own update mechanisms.
- Some apps prompt the user to update when they are launched.
- Some applications require the user to manually check for updates or download a new installer.

---

### Installing Apps

There are multiple ways to install applications in Windows.

#### 1. Microsoft Store

The Microsoft Store provides a curated and safer option for installing applications on Windows.

However, it is not available by default on Windows Server.

#### 2. From the Internet

In many environments, applications are installed by downloading an installer directly from a trusted vendor's website.

Installers commonly use formats such as:

- `.exe`
- `.msi`

The installer then guides the user through the installation process.

---

### Uninstalling Apps

In a Windows environment, there are multiple ways to uninstall programs.

Common methods include:

1. Using the **Microsoft Store** for applicable installed applications.
2. Using **Add or Remove Programs / Installed Apps** in Windows settings.
3. Using the application's built-in uninstaller.

## Diving into Settings

There are two primary ways in which Windows users can modify their environment.

### 1. Windows Settings

A modern, centralized location for configuring the system, device personalization, and security settings in Windows.

### 2. Control Panel

A legacy management interface that provides access to older system configuration tools that are still required for certain administrative tasks.

Windows Settings and Control Panel allow users to view and modify how their Windows system operates.

From these two applications, users can manage system preferences such as:

- Display settings
- Audio settings
- User accounts
- Application settings
- Network options
- Accessibility features
- Security configurations

## The Task Manager

Task Manager is a built-in Windows tool that allows users to monitor what is happening on their system in real time.

It allows users to view running applications and background processes, as well as check system performance such as CPU and memory usage.

### Task Manager Tabs

Task Manager has five main tabs that help users keep track of the system.

#### 1. Processes

Shows currently running applications and background processes, along with their resource usage.

#### 2. Performance

Provides graphs and statistics for system resources such as:

- CPU
- Memory
- Network

#### 3. Users

Shows currently logged-in users and their resource usage.

#### 4. Details

Provides a more technical view of running processes, including **Process IDs (PIDs)**.

#### 5. Services

Shows Windows services and their current status, such as whether they are **running** or **stopped**.

## Native Windows Security

It is important to understand that Windows itself provides several built-in security features.

These features help protect the system from:

- Malware
- Unauthorized access
- Unsafe applications
- Network-based threats

Windows provides these protections as part of the operating system, without requiring additional third-party security software.

### Windows Security

**Windows Security** is the central location for viewing and managing the security features available in Windows.

It provides access to different areas of protection, including:

#### 1. Virus & Threat Protection

Helps protect the system against viruses, malware, and other threats.

#### 2. Firewall & Network Protection

Helps manage firewall settings and protect the computer from unauthorized network connections.

#### 3. App & Browser Control

Helps protect against potentially dangerous applications, files, and websites.

#### 4. Device Security

Provides security features designed to protect the device and its hardware.

---

## Windows Defender Firewall

The **Windows Defender Firewall** helps protect the computer by controlling network traffic.

It can:

- Monitor network connections.
- Allow or block network traffic.
- Apply rules to network connections.
- Provide different levels of protection depending on the network profile.

### Network Profiles

Windows Defender Firewall uses different network profiles depending on the type of network the computer is connected to.

#### 1. Domain Network

Used when the computer is connected to a domain network.

#### 2. Private Network

Used for trusted networks, such as a home or lab network.

#### 3. Public Network

Used for untrusted networks, such as public Wi-Fi.

### Windows Defender Firewall with Advanced Security

**Windows Defender Firewall with Advanced Security** provides more detailed control over firewall rules.

It allows users to:

- View inbound rules.
- View outbound rules.
- Create new rules.
- Modify existing rules.
- Examine the properties of individual rules.

Firewall rules can specify details such as:

- Rule name
- Direction
- Program
- Protocol
- Ports
- Network profile
- Action

- **CLI** environments
- **GUI** desktop environments

### DOS (Disk OS)

A computer OS that provides a file system for operations such as reading, writing, & erasing data on a disk.

It is a non-graphical, line-oriented command-driven computer OS designed for the IBM PC.

Several variations of DOS were developed, such as MS-DOS & PC-DOS (IBM).
