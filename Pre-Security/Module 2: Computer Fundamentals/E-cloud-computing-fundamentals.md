# E: Cloud Computing Fundamentals

## Evolution to the Cloud

### 1. Physical Servers Era (1960s – Early 2000s)

- Physical servers in companies/buildings.
- One server = one job.
- Expensive and slow to scale.

### 2. Virtualization (1999 – 2006)

- Multiple virtual servers on one machine.
- Better hardware utilization.
- Faster provisioning.

### 3. Automation & Remote Management (2003 – 2006)

- Servers managed over the internet.
- Easy automation.
- Infrastructure became faster & flexible.

### 4. Cloud Computing — AWS Launch (2006)

- Rent virtual computers & storage on demand.
- No hardware ownership.
- Elastic scaling in minutes.

### 5. Modern Cloud Era (2012 – Today)

- AWS, Azure, Google Cloud.
- Containers.
- Focus on apps, not servers.
- Global-scale platforms.

---

## Cloud Benefits & Characteristics

### 1. Scalability

Easy scale up/down as your application's needs change.

### 2. On-Demand Self-Service

Create or remove servers & storage instantly, without waiting for hardware.

### 3. Security

Cloud providers protect the infrastructure with strong security measures.

### 4. Pay Only for What You Use

You are charged based on usage, not upfront costs.

### 5. High Availability

Applications keep running even if part of the system fails.

### 6. Global Access

Your application can be accessed by users anywhere in the world.

## Types of Cloud

### 1. Deployment Types

#### a) Public Cloud

- Cloud infrastructure is owned & managed by a third-party cloud provider.
- Resources are shared among multiple customers.
- Used by startups, websites, & global apps because it is affordable, easy to scale, & requires no infrastructure management.
- Public cloud services are preferable for nearly every use case.

#### b) Private Cloud

- Cloud infrastructure is dedicated to a single organization.
- Used by banks, healthcare, & government organizations because it offers great control, customization, & compliance for sensitive data.
- Generally more expensive & requires more management than public cloud.

#### c) Hybrid Cloud

- Combination of public & private cloud environments.
- Used by companies like e-commerce platforms that need to keep sensitive data private while still scaling publicly during high demand.
- Useful when an organization needs both:
  - Security & control of a private environment
  - Scalability & flexibility of a public environment

---

### 2. Cloud Service Models

#### a) Infrastructure as a Service (IaaS)

- You rent basic computing resources from a cloud provider.
- Includes:
  - Virtual servers
  - Storage
  - Networking
- Provider manages:
  - Physical hardware
  - Underlying infrastructure
- You manage:
  - OS
  - Applications
  - Your data
- Gives you more control, but also requires more management.

#### b) Platform as a Service (PaaS)

- The provider manages the infrastructure & OS.
- You focus mainly on building, deploying, & running your application without worrying about servers or the OS.
- Provides less infrastructure control than IaaS but makes development easier.

> You manage the application.

#### c) Software as a Service (SaaS)

- You use a complete application over the internet.
- The provider manages everything, & you access the software through a browser or app.
- Examples:
  - Gmail
  - Zoom

## Notes

### 1. EC2

**Elastic Compute Cloud (EC2)** is a service provided by AWS that allows you to rent virtual PCs on the cloud.

The machines can be used just as any regular PC, & their specs can be customized according to your specific needs.

---

### 2. AI

**Artificial Intelligence** is technology that enables computers & machines to simulate human behavior, like learning & reasoning.

---

### 3. AWS

Amazon Web Services is a comprehensive cloud computing platform offered by Amazon.

It provides a wide range of services such as networking, analytics, computing power, storage, databases, and more, delivered over the internet on a pay-as-you-go basis.
