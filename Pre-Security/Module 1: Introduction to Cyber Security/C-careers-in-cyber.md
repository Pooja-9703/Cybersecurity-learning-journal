# C. Careers in Cybersecurity

## 1. Security Analyst

### Role

Responsible for maintaining the security of an organization's data.

Security analysts are integral to constructing security measures across organizations to protect the company from attacks. Analysts explore and evaluate company networks to uncover actionable data and recommendations for engineers to develop preventative measures. This role requires working with various stakeholders to understand security requirements and the current security landscape.

### Responsibilities

- Work with various stakeholders to analyze cybersecurity throughout the company.
- Compile ongoing reports about network security, documenting security issues and response measures.
- Develop security plans using research on new attack tools, trends, and security measures needed across teams to maintain data security.

---

## 2. Security Engineer

### Role

Design, monitor, and maintain security controls, networks, and systems to help prevent cyberattacks.

Security engineers develop and implement security solutions using threat and vulnerability data, often provided by other members of the security workforce. They work to defend against web application attacks, network threats, and evolving attack techniques. Their goal is to implement security measures that reduce the risk of attacks and data loss.

### Responsibilities

- Test and screen security measures across software.
- Monitor networks and reports to update systems and mitigate vulnerabilities.
- Identify and implement systems needed for optimal security.

---

## 3. Incident Responder

### Role

Identifies and mitigates attacks while an attacker's operations are still unfolding.

Incident responders handle security breaches by creating plans, policies, and procedures that organizations follow during and after an incident. The role often requires making decisions in real time while attacks are in progress. The objective is to minimise damage, protect company data, preserve reputation, and reduce financial impact.

### Incident Response Metrics

| Metric | Description |
|---------|-------------|
| **MTTD (Mean Time to Detect)** | The average time it takes an organization to identify a security threat, incident, or technical problem. |
| **MTTA (Mean Time to Acknowledge)** | The average time between the initial alert and the service provider (e.g., SOC L1 analysts) taking action. |
| **MTTR (Mean Time to Response)** | The average time between the initial alert and responding to it (e.g., malware removal, password reset, or system restore). |

### Responsibilities

- Develop and maintain an actionable incident response plan.
- Support incident response measures and security best practices.
- Produce post-incident reports and improve future responses using lessons learned.

## 4. Digital Forensic Examiner

### Role

Responsible for using digital forensics to investigate incidents and crimes.

### Responsibilities

- Collect digital evidence while following legal procedures.
- Analyse digital evidence to answer questions related to the investigation.
- Document findings and report on the case.

---

## 5. Malware Analyst

### Role

Analyses all types of malwares to understand how they work and what they do.

A malware analyst examines suspicious programs, determines their behavior, and documents the findings. This role often involves reverse engineering, converting compiled programs into readable low-level code to understand malware functionality.

### Analysis Techniques

- **Static Analysis** – The process of analyzing malware without executing it.
- **Dynamic Analysis** – The process of analyzing malware by running it in a controlled environment, such as a sandbox.

### Responsibilities

- Carry out static analysis of malicious programs.
- Conduct dynamic analysis by observing malware behavior in a controlled environment.
- Document and report all findings.

---

## 6. Penetration Tester

### Role

Responsible for testing technology products for security loopholes.

Penetration testers, also known as ethical hackers, assess the security of systems, networks, and applications by attempting to discover vulnerabilities through authorized testing. The findings are used to help organizations fix weaknesses before they can be exploited by attackers.

### Responsibilities

- Conduct tests on computer systems, networks, and web-based applications.
- Perform security assessments, audits, and analyze security policies.
- Evaluate findings and recommend actions to prevent attacks.

---

## 7. Red Teamer

### Role

Plays the role of an adversary by attacking an organization and providing feedback from an attacker's perspective.

Red teamers perform targeted assessments by simulating real-world attackers. Unlike penetration testers, who focus on identifying vulnerabilities, red teamers evaluate an organisation's ability to detect, respond to, and recover from sophisticated attacks. These engagements may last for several weeks and are often conducted by external teams.

### Responsibilities

- Emulate threat actors to uncover exploitable vulnerabilities, maintain access, and avoid detection.
- Assess security controls, threat intelligence, and incident response procedures.
- Evaluate and report findings with actionable recommendations to improve security.
